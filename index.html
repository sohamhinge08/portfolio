An automated Python program that tracks the real-time position of the International Space Station and checks whether it is passing overhead at night, sending an automated email alert via SMTP.

What it Does:

Queries the Open Notify ISS API and Sunrise-Sunset API to compare current coordinates within ±5° latitude/longitude, calculates dark sky conditions, and triggers an email notification.
